## Copy rules

No em dashes (—) or en dashes (–) in any user-facing copy: site copy, page titles and metadata, newsletter issues (including citations and source titles), emails, and blog posts. Use a comma, period, colon, or rewrite the sentence instead. Number ranges use a hyphen (461-468). The only exception is a dash inside a URL, which must stay as-is so the link works.
